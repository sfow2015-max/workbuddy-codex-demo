# Windows 工作台日常启动与验收

2026-11-25 起，新建 Windows 工作台或更新已有工作台时，日常入口默认隐藏控制台。这项约定与项目采用的协作规则一起执行。

- **日常打开。** 从桌面快捷方式、开始菜单或项目说明指定的双击入口打开工作台时，用户直接进入应用窗口或浏览器页面。从双击到界面就绪、使用和退出期间，CMD、PowerShell、Python 以及启动器拉起的辅助进程都应避免弹出、闪现或留下控制台窗口。重复点击入口应能正常回到工作台。
- **异常反馈。** 后台启动失败时，在对话框或应用界面告诉用户失败原因和下一步。有独立诊断入口时，在使用说明中标明，用户主动打开它可以查看控制台输出。
- **交付验收。** Windows 首次交付及启动器、安装器或快捷方式变更后，从实际交付的日常入口验证首次启动、重复打开、退出和启动失败。已有安装还要在更新后点击原快捷方式验证。记录受测版本、能否打开应用、是否出现黑窗，以及失败提示是否可见。仅完成代码检查时，在回执中将 Windows 实机结果标记为待验。
